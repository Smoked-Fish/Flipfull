Google blocks signing in from KaiOS. You can fix this by adding your own client.

  1. In a Google Cloud project, turn on the People, Calendar and Gmail APIs and add the scopes userinfo.email, contacts, calendar and https://mail.google.com/. Publish the app.
  2. Create an OAuth client of the type Web application, with the redirect URI http://localhost/redirect/loginpages/redirect.html, and download its JSON.
  3. Copy the client_secret…json file to the phone's storage or SD card and press Import.
